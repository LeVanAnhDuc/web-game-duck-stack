# LANGUAGE — Ngôn ngữ EN / VI

Truy vết phía app: FR-28, FR-33 · US-02 · NFR-I18N-01, NFR-I18N-03 · ADR-0006.

- **REQ-LANGUAGE-01** Lần đầu mở, ngôn ngữ đoán từ trình duyệt: tiếng Việt thì giao diện tiếng Việt, `<html lang="vi">`.
- **REQ-LANGUAGE-02** Trình duyệt dùng ngôn ngữ khác EN/VI thì giao diện tiếng Anh.
- **REQ-LANGUAGE-03** Nút ngôn ngữ ở thanh trên mở Cài đặt; chọn VI/EN đổi toàn bộ giao diện ngay (cả `lang` của trang) và được lưu.
- **REQ-LANGUAGE-04** Ngôn ngữ đã lưu thắng ngôn ngữ của trình duyệt.
- **REQ-LANGUAGE-05** Số định dạng theo ngôn ngữ đang chọn, không theo máy (12,345 / 1.25 ở EN; 12.345 / 1,25 ở VI).
